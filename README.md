# Packraft PSI — aplikacja na telefon

Aplikacja webowa (PWA) do czujnika ciśnienia BLE w packrafcie (XIAO nRF52840 + BMP390L, firmware „Packraft-PSI”).

**Otwórz w Chrome na Androidzie:** https://rpherflik.github.io/packraft-psi-app/

- Menu ⋮ → „Dodaj do ekranu głównego”: działa jak aplikacja, także offline.
- Tryb demo bez czujnika: https://rpherflik.github.io/packraft-psi-app/?demo
